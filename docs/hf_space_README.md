# Tumor in context

Research prototype for exploring public BraTS brain-tumor MRI cases in 3D.
**Not for diagnosis.**

Demo data are public BraTS training cases (for example `BraTS20_Training_002`).
Upload/inference require a local SegResNet checkpoint and are disabled in this Space when no checkpoint is present.
